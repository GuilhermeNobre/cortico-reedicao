# Notas dos capítulos

Um arquivo por capítulo (`capitulo-NN.md`), escrito pelo Reeditor de cada capítulo. Cada nota traz:

- os termos da época que foram traduzidos e como ficaram;
- os termos **novos**, que não estavam na tabela do plano (`.agents/plano.md`);
- as dúvidas e decisões que ficaram em aberto na reescrita.

## Para o revisor

1. Leia a nota do capítulo antes de revisar o texto em `texto/reescrito/`.
2. Resolva cada termo novo e cada dúvida da forma mais adequada, comparando com o original em
   `texto/original/` e com as escolhas dos outros capítulos, para o livro ficar uniforme.
3. Aplique a correção no capítulo e registre na própria nota o que foi decidido.
4. Os termos que valerem para o livro todo vão para o glossário.
